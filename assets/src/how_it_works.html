Open-source AI agent skill · security-remediation-pack

From scan output to fixes each team owns

One command turns pentest and scanner results into a prioritized remediation package: every finding gets a reason, an owner, a deadline, fix steps and a retest check, split into one ticket queue per department.

1

Ingest

Raw results from the tools testers already use.

  • nmap XML (NSE vulners, smb-vuln)
  • Nessus .nessus
  • OWASP ZAP and Burp XML
  • Findings CSV / pentest notes
  • Asset inventory (criticality, zone, data)
  • Departments and leads
2

Normalize & merge

One finding per issue, even when three tools report it.

  • 18 finding categories
  • Stable fingerprint per service / URL
  • CVEs merged, KEV first
  • Unknown hosts flagged for the CMDB
  • Evidence kept word for word
3

Enrich & map

Facts from public catalogs, never invented.

  • CVSS v4.0 vector and score
  • CISA KEV (actively exploited)
  • FIRST EPSS probability
  • ATT&CK v20 Enterprise + ICS
  • D3FEND 1.6 countermeasures
  • OWASP WSTG v4.2 test IDs, CWE
4

Decide

SSVC-style: exploitation × exposure × impact × asset criticality.

P1 ACT3 daysP2 ATTEND14 d IT · 30 d OTP3 TRACK*45 d IT · 90 d OTP4 TRACK90 d IT · 180 d OT
  • Plain-language "why" line
  • KEV is always P1 or P2
  • Policy floors per category
5

Route & ship

RACI matrix sends each fix to the team that can do it.

  • Fix tickets per Responsible team
  • SOC detection while fix is pending
  • DPO ticket when personal data is hit
  • OT assets: OT-ENG + MOC sign-off
  • Jira CSV · ServiceNow JSON
  • DefectDojo · ATT&CK Navigator
